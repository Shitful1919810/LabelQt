## 拍摄约定

- 保持简体中文、Fedora 44 KDE 和一致主题；手册已说明其他平台视觉效果不同。
- 使用可公开分享的自制图源及示例译文。不要包含真实密钥、私人用户名/路径、未授权公开的稿件或通知。
- 主窗口和复杂对话框建议宽约 1200–1600 像素；小确认框按实际大小裁切，文字应清晰，不要缩小后再放大。
- 只截必要窗口或区域，不保留大片桌面；弹出菜单必须连同所属界面一起截。保留按钮和窗口边缘，不遮挡关键文字。
- 保存为 PNG，不预先添加箭头或说明文字，使用手册图注说明。新图不能只是空窗口，应准备能体现操作效果的内容。
- 不要替换其他工程的真实图片或修改正式稿件来制造演示状态，使用独立的测试目录。

## 检查与构建

在仓库根目录运行：

```bash
python scripts/build_manual.py --list-missing-screenshots
python scripts/build_manual.py --with-screenshots
```

第二条会生成 `dist/LabelQt-user-manual-zh_CN.pdf`，已补的图正常显示，未补的图继续占位。
正式发布前使用 `--require-screenshots`，防止把缺图版本作为完成版发布。
