# 校对轮次联动审查

本次针对 `44c7c17` 引入的轮次与批注进行静态审查、结构整改和回归验证。
范围包括保存/另存、备份恢复、外部重载、自动化任务、页面管理、匹配与审阅、UI 和 HTML 输出。

## 已整改问题

| 问题 | 影响 | 整改与验证入口 |
| --- | --- | --- |
| 备份恢复未更新文档会话 | 服务层旧校对撤销命令仍可能回放到恢复后的工程，依赖 UI 清空撤销才安全 | `ProjectController::adoptProject` 统一状态安装；测试恢复后的旧命令、旧任务和旧提交 token |
| 轮次缓存只看路径与注释 | 重载相同文件时可能复用旧的内存身份，尤其是旧基线迁移 | 缓存键加入文档会话，与打开、重载、恢复共用生命周期 |
| 结果窗口从差异反推页面计划 | 丢失可信 ID 标志及未变化页，结果可能在打开窗口后改变 | 窗口接收完整 `ProjectComparisonPlan`；测试同文删除/新建在窗口中仍为两项 |
| 人工配对切换整页为启发式匹配 | 无关标签被重新误配 | 指定项手动配对，其余项保留 ID 策略；统一顺序反转计算 |
| 批注混用原始 Label 与新关联目标 | 页面批注关联到 Label 后，该 Label 删除却不显示失联；改名后页名陈旧 | `ProofreadNote` 统一目标选择；列表按目标定位和显示当前页名 |
| 纯批注没有完整双侧索引 | 左侧不选中对应 marker，页面批注在 HTML 中生成角落假标记 | 从两侧快照分别定位；没有标签索引则不绘制标记 |
| 报告只按显示文件名合并 | 被删除页和同名新页的图片、标记混在一起 | 按左右页面配对分组，显示名称不再充当缺失侧的查找目标 |
| 审阅指纹不含对象身份 | 新建同文标签可能继承旧的已查看状态 | 轮次指纹纳入对象 ID；批注解决不改变正文版本指纹 |
| 校对计算同步运行且无异常边界 | 大工程阻塞 UI，计算异常可能越过 Qt 事件处理 | 与外部比较共用后台任务入口；快照隔离、异常反馈和中止丢弃结果 |
| 空页面工程禁用完成/清除轮次 | 移除全部页后轮次生命周期无法结束 | 菜单区分“存在工程页面”与“存在校对记录” |
| 损坏的批注标识被当作空值 | 标签批注可能变成页面批注，部分关联字段被静默丢弃 | 严格验证字段类型、完整关联和版本，拒绝提交并保留原记录 |

外部比较后的跳转也改为文档会话校验与 UUID 定位，不直接把快照行号应用到当前工程。
UI 预览直接读取左右工程快照的标签数组，不再另行重建一份基线标签。
本次不改 TXT 正文格式，不增加第三方依赖，不更改自动化协议。

## 手册覆盖核对

| 场景 | 手册章节与边界 |
| --- | --- |
| 开始、修改、批注、完成、交接 | 校对章节增加完整操作顺序，说明单轮替换和保存 TXT/HTML |
| 修订交互与普通编辑 | 说明悬停只同步文本、列表点击聚焦、多选保护，补充右下编辑框入口 |
| 批注生命周期 | 当前项/全工程筛选、解决、重新关联、完成后正文只读、历史归属不变 |
| 差异筛选和报告 | 修正“顺序”并非独立类型、“格式”可与“文本”并存；说明筛选交集和摘要并集 |
| 后续页面管理 | 移除页不删除图片、校对记录保留、预览非历史图片像素归档 |
| 外部修改和恢复 | 比较、另存、重载、覆盖、保留的区别；恢复不自动拼接两份批注 |
| 自动化 | 参数与密钥、取消、提交校验、整体编辑限制；外部进程非沙箱且无独立授权窗口 |
| 合并与经典 LabelPlus 交接 | 合并产生新身份且不合并轮次；外部注释保真无保证，建议携带 HTML |
