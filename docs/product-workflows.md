# 恢复、页面草稿、全文替换与审阅

本文描述当前开发版本的实际行为。原始设计见 [产品提案](product-design-proposal.md)。

## 备份与恢复

- 入口：文件 → 备份与恢复。可选择其他工程检查备份；加载时发现较新的备份或未完成文件事务，会出现非模态入口提示。
- 备份记录包含工程路径、时间、快照路径和 SHA-256。预览只读，不替换当前工程；“恢复为副本”只创建新文件，拒绝覆盖已有目标。
- “替换当前工程”先处理当前编辑并备份原稿。成功后才替换内存工程、重建视图、清空普通撤销历史。失败不宣称恢复成功。
- 另存、备份和恢复保留图片实际路径。跨目录图片引用写入统一 metadata 的 `imagePaths` v1 section；合并来源通过 `ProjectLocationService` 重定位。旧工具可以读正文，但可能忽略这类私有图片引用。
- 保存前比较成功加载或保存时的内容摘要。外部修改冲突可比较、另存、重新载入或明确确认覆盖。覆盖确认只针对当时看到的磁盘版本，再次变化会拒绝写入。这不是对任意外部程序的排他文件锁。
- `.labelqt-rename-*.json` v2 记录包含文件摘要和操作前后的工程快照。恢复服务先验证全部文件，再恢复原文件名或完成操作。无法唯一识别、文件被改动、快照不符或旧版记录，不自动回放。
- `backupMaximumCount` 为每工程自动备份保留上限，0 表示全部保留。只清理同一备份目录内、索引标为自动且摘要仍匹配的快照；手工备份、被外部修改的备份及未完成事务材料不会因此删除。清理失败时保留剩余文件。
- 同名备份或索引不会被后一次备份覆盖。并发创建或索引写入失败会报告备份失败，保留已有材料；无索引快照仍可手动打开。

旧版没有索引的普通 TXT 备份仍可手动打开，但不会自动推断其归属。多文件恢复不提供硬件级断电原子性；发生错误时保留记录和临时文件，先恢复再继续写入。

## 外部工程修改

打开的 TXT 被其他 LabelQt 实例或文本编辑器修改时，窗口会提示磁盘版本变化。
可比较差异、另存当前编辑稿、重新载入，或选择“保留当前版本”继续编辑。
暂不处理时状态栏保留入口；同一磁盘版本不会反复询问，后续正常保存仍会检查冲突。

重新载入会清空撤销历史。有未保存修改时，先备份到偏好设置的备份目录，再加载磁盘版本；
备份失败、文件损坏或确认期间磁盘再次变化时不替换当前工程。
本地修改副本可从“备份与恢复”查看，不受自动备份数量上限清理。
尽量保留当前页面、选中标签、缩放和视图中心；已删除或无法辨认的标签不恢复选择。

页面管理、校对等模态窗口以及自动化任务期间延迟询问。文件被删除或暂时无法读取时保留当前编辑稿，
继续检测其恢复，亦可另存到其他位置。检测不是跨程序排他锁，仍应避免多个工具同时保存同一工程。

## 页面管理

一张表区分“当前图片”“待应用目标”“输入预览”“原页序”。当前输入只产生预览；点击“加入待处理”才修改草稿。多次加入会累计，重排不会清空已有目标。

- 范围默认“所选页面”，可显式选“全部页面”；零选中不会变成处理全部。
- 顶部“全部页面 / 待处理 / 有问题”只筛选展示，最终提交覆盖完整草稿。筛选状态下禁用拖放，避免隐藏行造成落点歧义。
- 工具菜单和表格右键菜单可清除选中页或全部待处理操作。移除页面会同时移除该页待处理文件指令，局部撤销可以一起恢复。
- 缺失页可“指定图片”或“在文件夹中匹配”。优先精确名称，再匹配同名主体的可读图片；多个候选交给用户选择。跨目录只修改引用，不复制或修改目标图片，允许不同扩展名。
- 窗口内撤销只作用于草稿。点击确定后，文件更新与当前页序一起确认和提交；失败留在窗口。纯页序操作继续使用主工程普通撤销；有待处理文件或引用变更时，提交前后保存工程，成功后清空普通撤销。

`PageManagementDraft` 持有原始工程快照、页面身份、顺序和 pending 计划。`PageOrderListModel` 派生显示并管理局部 UndoStack；窗口不维护第二份业务映射。格式和文件校验仍由 `ProjectImageRenameService` 负责。

## 工程内查找与替换

编辑 → 工程内查找（默认 Ctrl+F）打开右侧面板。F3 / Shift+F3 定位下一项 / 上一项，三项均可在偏好设置中修改。保存偏好前检查与其他配置动作、自动化和常见内置键位的冲突；直接编辑 JSON 带入冲突时，保留菜单入口但停用冲突的查找快捷键并提示。

支持全工程、当前页、页码区间、分组和区分大小写。输入查询不自动跳页；点击结果或使用上下一项才定位并高亮原文区间。查询与替换文本支持真实换行，不把两个字符 `\n` 当成换行。

展开替换后，可替换当前项，或预览全部替换并逐项取消勾选。预览中的替换后文本按同一标签所有已选命中组合计算，并显示实际匹配数与变更标签数。整批通过 `LabelEditController` 提交，一次撤销 / 重做。

`ProjectTextSearchService` 返回原文区间和工程内容指纹；预览后文本、页序、分组或标签发生变化，旧结果不能直接应用。当前实现使用延迟触发的同步普通文本搜索，无正则或后台大工程搜索。

## 审阅记录与人工配对

校对窗口增加未查看、已查看、待确认三种状态。点击、悬停、滚动不自动改变状态；可多选批量标记，使用“下一条未查看”，或按状态与原三个筛选取交集。

审阅列使用红色问号（未查看）、绿色勾（已查看）、黄色警示（需确认）及文字，选中行仍保留图标颜色。点击审阅列可切换已查看 / 未查看；底部状态框可对多选项设定三种状态。局部撤销 / 重做覆盖状态和人工配对。

批注编辑及历史批注入口已移除。旧批注仍随会话保留，在条目提示及 HTML 中可读取，不改动译文，不自动继承旧的已查看状态。

误配成新增与删除的条目，可选择其中一项并“与另一侧配对”。只允许同一页面配对关系内的一对一约束；表格明确显示人工配对，可以取消。服务验证两端的页面、索引、文字、分组和坐标后，移出自动匹配集合重新比较，不在 UI 中合并两行。

工程内基线的记录存在 `LabelQtMetadata.reviewSession` v1 中，关闭校对窗口后形成一条主工程撤销记录，需要正常保存工程。开始 / 结束基线同步清除本轮记录，撤销可恢复。外部工程对比记录只写入本机应用数据目录 `review-sessions`，不写入任一 TXT；比较上下文包含双方路径与左侧基准内容摘要。

状态和批注按变更指纹匹配，不按表格行号匹配。指纹变化则默认为未查看；过期人工配对会提示并弃用，不猜测新归属。外部对比更换基准内容会使用独立会话；旧会话文件保留，但当前窗口不会跨会话合并历史。

HTML 仅导出当前筛选结果，筛选信息包含审阅状态，正文包含每项状态、批注与人工配对标记。批注按纯文本转义，不作为 HTML 执行。恢复和保存冲突中的只读比较不写审阅记录。

筛选栏显示可见 / 总变更数，并提供重置筛选按钮；人工配对和解除配对收纳到工具菜单。查找面板的范围、分组、大小写选项可折叠，已启用筛选会显示“筛选（已启用）”。

## 偏好设置草稿

- 同一主窗口只保留一个偏好设置窗口，再次打开会激活已有窗口并保留草稿。
- “应用”先保存到磁盘，成功后才使设置生效，不关闭窗口。关闭或按 Esc 时若有未应用修改，可选择应用、丢弃或取消；保存失败仍保留窗口和草稿。
- 高级菜单提供重新载入、只读 JSON 预览和外部文本编辑入口。重新载入只更新草稿，不立即应用；丢弃尚未保存的本地修改前会询问确认。
- 成功重载的草稿视为已保存，但与运行中配置不同时仍可直接“应用”，无需先修改字段；关闭时也会询问是否应用。重载只确认丢弃尚未保存的本地修改，不把已保存但未应用的配置误当成本地编辑。
- 搜索按分类名、设置标签、选项及表格文字筛选分类；JSON 预览按需打开，不占用常驻分类。
- 磁盘内容被外部修改时拒绝保存，保留草稿，需重新载入后再编辑和应用。锁占用可稍后重试；文件损坏或无法读取时不会以默认值静默覆盖原文件。没有自动合并或强制覆盖入口。
- 偏好 JSON 限制为 4 MiB、10000 个值节点（含根与容器）、32 层深度。读取或保存超限时保留已有文件和草稿，不应用新设置。

并发检查及协作式文件锁的限制见 [偏好设置保存](persistence-safety.md#偏好设置保存)。

## 验证与边界

`ProductWorkflowTests` 覆盖外部保存冲突、备份校验与跨目录路径、文件循环恢复、外部修改拒绝恢复、草稿累计与删除剪裁、批量替换撤销、过期配对、报告转义、窗口初始化和关闭。它与 `PersistenceSafetyTests` 一起用于 ASan / UBSan 回归。

当前窗口级自动测试使用 Qt offscreen。Windows 原生文件权限、平台样式和大体量真实稿件仍应在发布前单独验收。新增功能没有引入第三方依赖，文本差异仍经过原 `TextDiffService` 安全策略。

外部修改检测由 `ExternalProjectChangeTests` 覆盖文件监听、延迟提示、重载确认及备份失败；
它与现有持久化、工作流和自动化测试一起纳入 Linux Debug 与 ASan / UBSan 回归（未启用泄漏检测）。
这些验证不等同于所有平台、断电情景或任意外部程序并发写入的完整保证。

首版在表现上做了简化：人工配对入口位于校对窗口底部工具区；文件提交确认列出改名、引用修复和移除数量，并说明页序一并保存，尚未单列重排数量。恢复中心依赖新增备份索引，不自动收录无索引的旧备份。同步全文搜索和跨会话历史汇总的限制见上文。
